# Gid Tourist — перевірка Geoapify під час створення партнера

## Налаштування Railway (Backend)

1. Створіть API-ключ у https://myprojects.geoapify.com/ (Projects → API Keys).
2. Railway → Gid Tourist → Backend → Variables: `GEOAPIFY_API_KEY` = фактичний ключ Geoapify. Не вставляйте ключ у Frontend та не публікуйте його в Git.
3. Перевірте, що `ADMIN_API_KEY` (або `GEO_ADDRESS_SIGNING_SECRET`) задано: backend підписує ним обрані адресні підказки.
4. Redeploy Backend, потім оновіть адмінпанель у браузері.
5. Немає потреби вмикати Google Geocoding API. Ключ Google Maps для інших, не пов’язаних з адресною формою, функцій може залишатись.

## Перевірка без запису в БД

* В адмінці «Партнери → Новий партнер» введіть «Кривий Ріг» і **виберіть** місто з підказок.
* Введіть вулицю і **виберіть** її з підказок. Далі номер будинку і вибір із підказок.
* Перевірте сформовану адресу. При відсутності точної адреси/номера не припускайте координати: уточніть адресу або виберіть точку на карті (Leaflet / OpenStreetMap).
* Перевірте ручний вибір точки на мапі. Адреса за координатами має визначатися Geoapify без звернення до Google Geocoding.
* Після вибору адреси можна створити тестового партнера і перевірити, що `places.lat`, `places.lng` і `places.address` відповідають обраному місцю. Для реальної БД використовуйте окремий тестовий заклад та не видаляйте наявні записи.

## Очікувані помилки

* Якщо `GEOAPIFY_API_KEY` відсутній у Backend: чітке повідомлення про налаштування Geoapify, а не Google API.
* HTTP 403 / 429 від Geoapify: перевірити дозволи API-ключа, обмеження ключа й квоту в Geoapify.
* Якщо змінили код, але бачите старий текст Google Geocoding API: перевірте, чи Railway розгорнув новий Backend і чи Frontend звертається до нього.

## Зміни

* `backend/src/modules/stage2/stage2.service.ts`: адресні автопідказки, підписані адреси, reverse geocoding — тільки Geoapify; немає Google fallback при помилці геокодування.
* `backend/.env.example`: уточнено призначення `GEOAPIFY_API_KEY`.

Зміни **не** зачіпають фінансові операції, таблиці PostgreSQL, правила QR, дизайн адмінпанелі, туристичний каталог, Google Places-фото й маршрутизацію.
